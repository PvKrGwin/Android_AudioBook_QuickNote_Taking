# BLE-M3 test results

## Already confirmed

- Bluetooth name: `BLE-M3`
- Middle single tap: play/pause
- Middle double tap: like
- Up/Down short press: scroll
- Up/Down long press: volume
- Left long press: lock the phone screen
- Right long press: go to the Android Home screen
- Bluetooth earphones can remain connected simultaneously
- Middle button still controls YouTube with earphones connected

## Still to confirm

- Middle-button behaviour while the phone screen is locked
- Whether the first press after approximately ten minutes idle performs its
  action or only wakes/reconnects the remote
- Exact Android key code and scan code for every button/gesture
- Whether double tap is a distinct event or two rapid single-tap events

## Provisional mapping decision

- Preferred Rider Notes trigger candidate: middle single tap
- Keep Up/Down long presses for their normal volume behaviour
- Keep Left/Right long presses reserved for Android lock/Home behaviour
- Do not consume or remap the system-control actions during normal use
